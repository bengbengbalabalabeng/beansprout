# Beansprout MCP Starter

This artifact has no code. It brings in `beansprout-spring-boot-starter` and Spring AI's MCP
server, `spring-ai-starter-mcp-server-webmvc`. The MCP tools live in
`beansprout-spring-boot-autoconfigure`, whose sources and Javadoc jars hold the code.

Maven Central asks for a sources jar and a Javadoc jar next to every jar, so this file stands in
for both.
